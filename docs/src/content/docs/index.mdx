Five lines, a real clinical-trial cohort, a publication-ready figure:

```python
import tausurv as ts

ts.plot.set_style("publication")
X, Y, delta = ts.datasets.load_pbc()
ts.plot.km(Y / 365.25, delta, xlabel="years from registration")
```

![Kaplan-Meier survival curve on the PBC trial cohort, with a 95% confidence band and an at-risk table below the time axis.](/figures/landing_km.svg)

`tausurv` is organised around three principles. **The estimand comes before the method.** Survival probability, hazard rate, restricted mean survival time, cumulative incidence: pick the quantity that matches the question, then reach for a model. **Every estimate carries an assumption.** Independent censoring, proportional hazards, conditional ignorability: each appears next to the estimate it produces, not in an appendix. **Plotting is publication-grade by default.** One call to `ts.plot.set_style("publication")` configures matplotlib so user code can read as a story about the analysis instead of a stack of `rcParams` boilerplate.
