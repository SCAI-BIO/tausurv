---
title: Installation
description: How to install tausurv.
---

```bash
pip install tausurv
```

tausurv requires Python 3.12 or newer. Optional features come as extras:

| extra | adds |
|---|---|
| `tausurv[plot]` | plotting with matplotlib |
| `tausurv[boost]` | `SurvivalBoost`, via scikit-learn |
| `tausurv[tune]` | hyperparameter search and nested cross-validation, via Optuna |
| `tausurv[deepsurv]` | the four DeepSurv benchmark tables stored as HDF5 |

Combine them as needed, for example `pip install 'tausurv[plot,tune]'`.

## PyTorch

The neural models in `tausurv.nn` need PyTorch. It is not installed
automatically, because the right build depends on your hardware (CPU, CUDA or
ROCm). Install it first by following the
[PyTorch instructions](https://pytorch.org/get-started/locally/). Everything
outside `tausurv.nn` works without it.

## From source

The repository is a uv workspace:

```bash
uv pip install torch --index-url https://download.pytorch.org/whl/cpu
uv sync --all-packages --all-groups
```
